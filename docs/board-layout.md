# ユニバーサル基板 実装ガイド

図面：[board-layout.svg](board-layout.svg)　／　回路の論理構成：[schematic.svg](schematic.svg)

ブレッドボードで運用してきた現行構成（Step 5 RTC + Step 6 増幅段）をユニバーサル基板へ移設するための、部品配置・穴座標・配線手順をまとめる。Step 7（GPS）の部品領域とパターンも同時に確保し、着手時に基板を作り直さずに済むようにしてある。

---

## 1. 前提と座標系

| 項目 | 値 |
|------|-----|
| 基板 | 秋月 B タイプ 95×72mm（2.54mm ピッチ） |
| 座標 | `C` = 列（左→右）、`R` = 行（上→下）。例：`C7-R11` |
| 使用領域 | C1〜C36 × R1〜R24 |
| Tang Nano 9K | ピンソケットで着脱可能とする |
| ボードの向き | USB-C を**左**。J5（信号）が下列、J6（電源）が上列 |

**C1・R1 は基板の物理的な端ではなく「使用開始位置」である。** ユニバーサル基板の穴数は製品によって 24〜26 行 × 36〜38 列と差があるため、左上に 1〜2 穴の余白を残した位置を C1-R1 として基準にする。

### Tang Nano 9K のヘッダ

公式回路図の J5/J6 端子表および Sipeed の実機ピンマップで確定した並び。**本プロジェクトが使う信号はすべて J5 の連続する 6 ピンに収まっている。**

| ヘッダ | 位置 | 内容 |
|--------|------|------|
| **J5**（USB-C を上にして左列） | 5〜10 番目 | pin 25, 26, 27, 28, 29, 30 |
| **J6**（同・右列） | 18 / 23 / 24 番目 | +5V / GND / +3.3V |

J5 も J6 も 1 番ピンが USB-C 側にある。したがって USB-C を左に向けて基板に載せると、**信号は左寄り（C7〜C12）、電源は右寄り（C20〜C26）**に現れる。この非対称が、電源を横方向の幹線で配る設計の理由になっている。

ソケットの列間隔は **9 ピッチ（22.86mm）**。R2 と R11 に配置する。

## 2. 部品表

移設する部品はブレッドボードからそのまま流用できる。新規調達が必要なのは基板・ソケット・端子台・配線材のみ。

### 新規に必要なもの

| 品目 | 数量 | 用途 |
|------|------|------|
| ユニバーサル基板 B タイプ 95×72mm | 1 | — |
| ピンソケット 1×24（分割ロングピンソケット等を切って使用） | 2 | Tang Nano 9K の受け |
| ねじ端子台 2P 5.08mm ピッチ | 1 | TB1：ループアンテナ |
| ねじ端子台 5P 5.08mm ピッチ | 1 | TB2：GPS（Step 7。今回は未実装でも可） |
| CR2032 基板実装用ホルダ | 1 | BT1 |
| ポリウレタン銅線 UEW 0.4mm 以上 | 少量 | +5V 系・増幅段の GND |
| ポリウレタン銅線 UEW 0.26mm 程度 | 少量 | 信号・+3.3V |

**配線はすべて UEW（ポリウレタン銅線）で行う。** すずメッキ線は使わない。理由と条件は §4 を参照。

C01u（0.1μF）は Q1 のすぐ右（C9）に置く。バイパスコンデンサはスイッチング素子に近いほど効くため、C47u（C11）より内側に配置している。

## 3. ネットリスト

### 電源の幹線

Tang Nano 9K のヘッダに **GND は J6-23 の 1 本しかない**。したがって全ての GND は最終的にこの 1 点へ集まる。各ネットの幹線を下表の経路で引き、そこから各部品へ分岐させる。R20 / R14 / R24 という行は推奨経路であり、UEW なので厳密に沿わせる必要はない。

| ネット | 経路 |
|--------|------|
| **GND** | `C25-R2`（J6-23）→ `C25-R24` を縦に降ろす<br>`C1-R24` 〜 `C36-R24` を横一本（幹線） |
| **+5V** | `C20-R2`（J6-18）→ `C20-R20` を縦に降ろす<br>`C1-R20` 〜 `C20-R20` を横一本（幹線） |
| **+3.3V** | `C26-R2`（J6-24）→ `C26-R14` を縦に降ろす<br>`C19-R14` 〜 `C27-R14` を横一本（幹線） |

## 4. 配線材と交差の扱い

**全配線を UEW（ポリウレタン銅線）で行う。** 被覆があるため、配線どうしの交差でも、SK1・SK2 のランド上を通過する場合でも短絡しない。したがって経路を最短で自由に引いてよく、交差を避けるための引き回しは不要である。

この方式が成立する根拠は動作周波数の低さにある。40kHz において UEW 0.26mm の 100mm は抵抗 0.032Ω、リアクタンス 0.025Ω 程度であり、すずメッキ線のレールが持つ低インピーダンスの利点は実質的に効いてこない。基板全体でも電流は 100mA オーダーである。

条件は 3 つ。

| 項目 | 内容 |
|------|------|
| **線径** | +5V 系と増幅段の GND は **0.4mm 以上**。ピーク電流が乗るため。信号と +3.3V は 0.26mm でよい |
| **色分け** | 色付き UEW を電源・GND・信号で使い分ける。すずメッキ線のレールが持っていた「見れば経路が分かる」性質が失われるため、色で代替する |
| **被覆処理** | 線の端は予備はんだで被覆を確実に飛ばしてから穴に挿す。はんだ部の熱で被覆が後退するので、線はランドから 1mm 以上離して這わせる |

被覆に頼る以上、**配線ごとの導通確認が必須**になる。予備はんだが不十分で見た目は付いているのに導通していない、という失敗が UEW では起こり得る。1 本引くごとにテスタを当てるのが結局は速い。

## 5. 実装手順

1. **ソケットの位置決め。** SK1・SK2 を仮挿しし、Tang Nano 9K が無理なく入ることを確認する。9 ピッチという列間隔は本図の前提であり、実機で必ず当たりを取ること。確認できたら対角の 2 ピンだけはんだ付けし、傾きを直してから残りを付ける。
2. **幹線を敷く。** GND（R24）→ +5V（R20）→ +3.3V（R14）の順。この時点ではまだ部品を載せない。
3. **J6 からの縦 3 本。** C25（GND）、C20（+5V）、C26（+3.3V）を降ろす。SK1 のランド列（R11）の上を通ることになるが、被覆があるので短絡はしない。ランドから 1mm 程度離して這わせる。
4. **低背部品。** 抵抗・セラミックコンデンサ・U2 を載せる。
5. **信号配線。** 最短に結ぶ。交差は気にしなくてよい。
6. **背の高い部品。** Q1、電解コンデンサ。
7. **端子台と電池ホルダ。** TB1・TB2・BT1 は最後。**これらの本体の下を通る配線は先に済ませておくこと**（あとから手を入れられなくなる）。

---

## 6. 通電前チェック

Tang Nano 9K を挿す前に、テスタで以下を確認する。**このチェックを省くと、短絡した基板に Tang Nano 9K を挿して壊すことになる。**

- [ ] 各配線が**両端で導通している**こと（UEW は予備はんだ不足で未導通になりやすい。1 本引くごとに確認するのが望ましい）
- [ ] +5V ⇔ GND が導通していないこと
- [ ] +3.3V ⇔ GND が導通していないこと
- [ ] +5V ⇔ +3.3V が導通していないこと
- [ ] SK1・SK2 の**使用していない**ピンが、いずれの電源とも導通していないこと（特に C20-R11 / C25-R11 / C26-R11 の周辺。被覆で守られているはずだが、はんだ熱で被覆が傷んでいないかの確認になる）
- [ ] C19-R13（VDD）と C19-R14（+3.3V 幹線）が同一ネットであること、かつ C19-R12 とは絶縁されていること
- [ ] D1 の帯（カソード）が VBAT 側＝上（C24-R18）を向いていること
- [ ] CR2032 を入れる前に、VBAT ライン ⇔ GND が導通していないこと

## 7. 通電後の確認

順序に意味がある。デジタル側の無罪を先に確定させてからアナログ側に進む（[knowledge.md §12.2](knowledge.md)）。

1. **AE-RX8900 の LED1 が 1Hz で点滅するか。** J3 ショートにより FOUT が基板上 LED に出る。連続点灯に見える場合は FSEL 未設定（32.768kHz のまま）であり、I2C が通っていない。
2. **Tang Nano 9K の LED6（pin 16）が消灯するか。** 点灯し続けるなら RTC が時刻を保持できていない。
3. **LED1（pin 10）のキャリア OOK。** 秒ごとに点滅し、マーカー秒が短く "0" の秒が長ければデジタル側は正常。
4. **Q1 とループアンテナの温度。** 通電 30 秒後に常温であること。発熱していれば `carrier_ant` の極性か配線を疑う。振幅 10% 区間で直流が流れている証拠であり、放置すると Q1 が壊れる（[knowledge.md §12.1](knowledge.md)）。
5. **電波時計の同期。** 移設前と同じ距離で同期することを確認する。

## 8. 現物合わせが必要な項目

図面上で寸法を仮定している箇所。実装前に現物で確認すること。

| 項目 | 図面の仮定 | 確認方法 |
|------|-----------|---------|
| ソケットの列間隔 | 9 ピッチ（22.86mm） | Tang Nano 9K を基板に当てる |
| 基板の穴数 | 36 列 × 24 行 | 実際の基板を数える。多い場合は余りを外周余白にする |
| CR2032 ホルダのピン間隔・外形 | 8 ピッチ（20.32mm）、φ20mm | 製品差が大きい。**C13〜C23 × R18〜R24 には他の部品を置かない**前提で位置を決める |
| Q1（TO-92）のピン配置 | 平面を奥に向けて左から C-B-E | **データシートで必ず確認する。** 誤ると増幅段が機能しないだけでなく Q1 を破壊し得る |
| 端子台の本体寸法 | 2P ≒ 4 列分、5P ≒ 10 列分 | 製品差あり。隣接部品との干渉を確認 |
